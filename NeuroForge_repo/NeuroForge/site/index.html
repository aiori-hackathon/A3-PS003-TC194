    Cost planner

    When does federated pay off?

    Analytic payloads with the same accounting as the simulator. Raw streaming grows with sensors × time; FedAvg grows with model size × clients × rounds.


    Decision support

    Best model for a byte budget

    Given a budget, pick the logged checkpoint with the lowest validation MAE among rounds that fit. Selection never looks at the test period.

    Method

    How the simulator works

      Core loop (simulate.py)

      FedAvg with byte accounting

      for t in 1..R:
    for client c in clients:            # K = 4
        B += nbytes(w)                  # download  14,988 B
        w_k = local_train(c, w, E=1)    # data stay in c
        B += nbytes(w_k) + 8            # upload    14,996 B
    w = Σ (n_k / n) · w_k               # FedAvg, Eq. (1)
    log(t, B, val_mae(w), val_rmse(w))
t* = argmin val_mae → evaluate test once

      Limitations we state up front

      • METR-LA is aggregated highway speed, not trip logs: privacy is a simulated motivation, not a property of this data.
      • Sharing updates is not a privacy guarantee; no differential privacy or secure aggregation is implemented.
      • Bytes are tensor payloads; TLS/TCP framing and retransmissions are excluded for every method.
      • Training windows are subsampled (one every 2 hours) for the CPU budget; the test period uses every window.
